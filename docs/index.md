# BookIt — Open-Source Booking Software for Entrepreneurs

**Free. Open source. Your data stays yours.**

BookIt is appointment scheduling software built with Laravel. Download it, self-host it, and own your booking system — no monthly SaaS fees, no data mining, no lock-in.

- **Source code:** [github.com/tawandajosephmutsena/book-it](https://github.com/tawandajosephmutsena/book-it)
- **License:** MIT — free to use, modify, and distribute
- **Hosted option:** $6/month (billed annually) or $9/month (billed monthly) — we install, maintain, and back it up for you
